# Project-original assets

Only the original procedural models and abstract livery artwork authored for this repository are dedicated to CC0 1.0 on 2026-08-04.

The runtime files are reproducibly generated by `scripts/generate-race-assets.mjs`. The color palettes are team-inspired, but the assets contain no external archive, commercial model, logo, copied texture, team word mark, or driver identifier. This CC0 dedication does not apply to third-party names, marks, or other rights referenced elsewhere in the private prototype.
